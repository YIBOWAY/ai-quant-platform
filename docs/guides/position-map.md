# 持仓地图 Position Map（界面路由：`/position-map`）

> 适用读者：第一次打开这个界面、却"看不懂它到底在干什么"的使用者。
> 安全红线：纯本地、仅模拟、只读行情，绝不接触真实下单 / 钱包 / 签名 / 券商。

---

## 一句话定位

`/position-map` 现在是**模拟账户的实时持仓看板**：展示账户净值（对比初始 100 万本金）、现金、已投资比例、各标的暴露（按「策略 / 手动」来源着色），以及每个持仓的均价、现价、未实现盈亏。无论你是在[模拟交易](paper-trading.md)里**手动下单**还是**一键策略再平衡**，都会即时反映到这里。

页面底部另有一块**「最近一次回测暴露（仅供对比）」**——那是研究产物，不是你的账户，明确分开放置以免混淆。

---

## 它解决什么问题 / 为什么存在

回答一个很自然的问题：**"我现在手上持有什么、各占多少、赚了还是亏了、离本金还有多远？"** 它是模拟账户的"组合视图"。

> 历史背景：旧版本里这张图的暴露其实来自"最近一次回测"，与模拟交易没有数据关系——那是当时令人困惑的根源。重设计后已改为**账户驱动**，本文描述的是改造后的真实行为。

---

## 它实际能做什么（基于真实代码）

页面是 Next.js 服务端组件（`src/frontend/app/position-map/page.tsx`），渲染时调用：

- `getPaperAccount()` → `GET /api/paper/account`：账户净值、现金、盈亏、已投资%、冻结状态、报价来源，以及逐持仓（数量 / 均价 / 现价 / 市值 / 权重 / 未实现盈亏 / 来源占比）。**这是页面主体数据来源。**
- `getPaperAccountLedger(12)` → 最近 12 条账本流水（驱动「账户流水」卡）。
- `getBacktests()` + `getBacktestDetail()`：仅用于页尾"最近一次回测暴露"对比块。
- `getHealth()`：全局安全开关展示。

具体模块（2026-06-11 重构后的布局）：

1. **顶部五个指标卡**：账户净值、总盈亏（金额 + %）、现金、已投资比例、未实现盈亏。账户接口不可达时数值显示 `--` 并给出红色横幅，避免误读。
2. **账户按标的的暴露条形图**（左列主卡）：每个持仓一条，宽度 = 该持仓市值 / 总投资市值；多头绿、空头红；每条按「策略 / 手动」来源分段着色并标注占比。卡片右上角汇总报价来源与时间。**空仓时显示空态卡 + 「打开模拟交易」引导按钮。**
3. **账户持仓表**（左列）：symbol / 数量 / 均价 / 现价 / 权重 / 市值 / 未实现盈亏 / 来源 / 价格来源，来源与价格来源列头有悬停释义。
4. **账户流水卡**（右列）：最近账本记录（成交 / 再平衡成交 / 入金 / 重置 / 冻结等），每条带来源徽章（手动 / 策略）、时间与成交后现金余额。
5. **安全状态面板**（右列）：`paper_trading` / `live_trading` / 账户是否冻结，并明示"仅模拟 · 不接触实盘"。
6. **最近一次回测暴露（页尾对比块）**：与账户**无关**，仅作研究对照，标题写明"研究产物，不是你的账户"，附「打开运行」链接。
7. **刷新控件**（页头）：手动「刷新」按钮 + 可选「自动：每 30 秒」轮询（只读重取）；页头另有「去下单 / 再平衡」按钮直达模拟交易页。

报价来源：整页顶部汇总报价类型；若各持仓来源不同会显示 `mixed`。持仓表逐只显示 `price_kind`，避免把某一只股票的实时快照误当成整页所有股票的报价来源。

持仓快照也会落盘到 `<data>/api_runs/paper_account/default/positions_snapshot.parquet`（含 `last_price` / `market_value` / `weight` / `unrealized_pnl` / `source_breakdown` / `price_kind` / `price_as_of`）。

## 操作步骤

1. 先到[模拟交易](paper-trading.md)手动买入或做一次策略再平衡。
2. 打开 `/position-map`，即可看到账户净值、暴露条与持仓表随账户变化。
3. 需要看最新盈亏时，点「刷新」或打开「自动：每 30 秒」（会按当前报价重算）。

---

## 字段与指标含义

| 名称 | 含义 |
|---|---|
| 账户净值 | 现金 + 持仓市值 |
| 总盈亏 | 净值 − 100 万初始本金（金额 + %） |
| 已投资比例 | 持仓市值 / 净值 |
| 权重 weight | 单个持仓市值 / 总投资市值 |
| 未实现盈亏 | 数量 ×（现价 − 均价） |
| 来源占比 | 该持仓中手动 vs 策略的数量占比 |
| 报价来源 | futu 实时快照 / 最近收盘 |

---

## 当前的局限

- 暂只展示多头持仓；做空 / 杠杆未建模。
- 自动刷新是 30 秒轮询，不是实时逐笔推流。
- 单一账户（`default`）。
- 底部回测对比块依赖存在的回测运行；没有回测时显示空态。
- 手机端隐藏桌面侧栏，通过顶部菜单导航；持仓表较宽时可在表格内部横向查看。

---

## 合理性评估与改进建议

改造后页面与账户**数据一致**，"手动 + 策略统一成一张图、对比 100 万本金"的目标已达成。后续可加：杠杆 / 现金行的更完整组合视图、按来源拆分的盈亏归因图、多账户切换。

设计与分阶段实现详见 [模拟交易 + 持仓地图 重设计](../design/paper_trading_position_map_redesign.md)。
