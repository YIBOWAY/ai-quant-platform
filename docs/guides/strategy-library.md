## 看懂某一期与整个回测

研究页的“每期选了谁，怎样成交”按信号日期展示当期分数、Top N 和目标权重。
候选股票池不是实际持仓；目标权重也不是成交，实际买卖、佣金和现金核对另列。
“整个回测的利润由哪些标的贡献？”按整个区间的买卖现金流、佣金及期末市值计算。
利润贡献高的股票不一定在当前 Top N；组合累计收益也不是某一只股票或单个因子的涨幅。

## 保存已有方案

1. 固定研究方案或 Grok 公式已有可用结果时，点击“保存到我的策略”。
   整轮研究部分失败不妨碍保存已完成单项；旧探索仍绑定自己的原始运行记录。
2. 普通回测从详情页保存。当前只导入 Futu 真实日线回测，须有原始输入快照及校验值；
   旧回测缺少 `input_prices.parquet` 时需要重新回测，不能用今天的数据冒充原输入。
3. 保存后进入“我的策略”，状态为“已保存 · 待验证”。保存本身不授予候选资格或分配资金。

保存的是公式、源码身份、股票池、初始化历史及参数共同确定的版本。
每条策略保留自己的调仓频率、因子窗口、方向、权重、仓位和现金规则；改名不改变计算身份。
旧固定方案保留原有语义，包括 12–2 月动量、月度 Top N、趋势转 SHY 和 R2 条件退出。

## 把新公式与已有因子组合

在“我的策略”点击“组合因子”，勾选注册因子及已保存或已冻结的 Grok 公式。
填写明确的股票代码、比较基准、各因子评分权重和方向，再选日／周／月调仓、Top N、
rank 或 z-score、单标的上限、总仓位上限和最小交易金额，点击“保存组合，等待验证”。

注册因子的回看参数参与计算；冻结公式保留表达式内部窗口，完整历史天数不能短于所需数据。
只在全部选中因子都有有效数据的共同股票样本中评分，不用零值或未来值填补缺行情。
因子评分权重决定信号贡献，不是下单持仓比例。入选标的等权后受仓位上限约束，余款留现金。
当前覆盖日线只做多规则；不支持的策略类型会拒绝，不会偷偷替换成每日 Top1。

## 验证结果怎样使用

“验证这条策略”对固定版本按 $10,000 模拟资金规模检查，不自动改公式或调参。
页面保留未通过原因；缺行情、缺完整形成窗口或缺证据时，不借用别的策略结果。

| 检查 | 回答的问题 |
| --- | --- |
| 双引擎执行核对 | 相同输入与目标下，Qlib 和 Platform 的收益、费用与期末净值能否对上；一致不等于发现了盈利能力 |
| 组件 IC / Rank IC | 因子或组合分数是否对应后续收益及其排序；IC 不等于组合收益或 Sharpe |
| 因子相关性 | 不同因子是否反复表达相似信号；不能代替对已运行策略的相关性准入检查 |
| 删除一个因子的对照 | 从保存评分减去该项贡献，在共同样本比较增量；不是重新拟合剩余规则 |
| Ridge 滚动对照 | 线性学习模型能否改善同样本预测；它是独立验证对照，不会自动替换固定权重或模拟规则 |

在“固定规则与验证详情”展开“因子贡献与学习模型对照”查看已记录统计。
未提供的数据显示未知；“加入后的 IC 变化”为完整组合减去去除该因子后的结果。
质量、成本敏感性与相关性准入仍走既有检查，不能因一次回测收益高而跳过。

## 近期研发与前瞻证据

新探索使用最近四年及最新已完成行情，以记录中的实际数据水位为准。
例如水位为 2026-09-08 时，当前窗口生成规则从 2022-09-01 起算。
已经看过并用于选择公式的历史属于研发与回顾性评价，刷新数据不会自动创造未见样本外。
历史 train / validation / test 分区名称也不证明未见；冻结后新到达且未用于修改规则的记录，
才可能形成前瞻证据。新定义调度接通本身不能预先证明这些策略已有自然模拟成交。

## 在 Hermes 中使用

[hqa-strategy-library Skill](https://github.com/YIBOWAY/Hermes-quant-agent/blob/main/skills/hermes/hqa-strategy-library/SKILL.md) 使用安装后的 `~/.hermes/scripts/hqa-strategy-library.sh`。
`list`、`factor-options`、`show ID` 只读；`import-study RUN PROFILE`、`import-backtest RUN`
和标准输入 JSON `compose` 保存版本；`validate ID --expected-digest DIGEST` 验证指定版本。
先从实际收据取得 ID、公式和 digest，不能凭名字猜测。需要新公式时沿现有受管 Grok 4.6/xhigh 路径；
此入口复用策略库服务，不是完整 RD-Agent FactorRDLoop，也不自行发明研究或观察周期。

`enable ID --expected-digest DIGEST` 仍要求用户明确请求该策略模拟且全部资格通过。
`execution_ready` 由实际调度能力判断，`strategy_definition_schedule_unavailable` 表示当前
运行版本尚未提供所需日历执行能力。2026-09-09 后续接入已补齐空预估订单的真实开盘重算；
仍禁止手动运行或补跑正式观察周期，不能直接写账或制造成交。
