# Polymarket 安全边界

Phase 11 严格限定为只读的研究/回测功能。

它不包含：

- 实盘交易
- 钱包签名
- 私钥处理
- 真实下单
- 代币转账
- 赎回
- 券商适配器集成

## API 规则

- 类凭证字段一律拒绝。
- 未知的 provider 一律拒绝。
- 默认 provider 保持为 `sample`。
- 安全声明页脚始终附加在 JSON 响应中。

## UI 规则

- UI 必须声明处于只读研究模式。
- UI 不得展示钱包、签名、提交订单、赎回或实盘控件。
- 扫描器和准回测结果必须被描述为假设性的。

## 运营规则

不要使用真实资金运行本系统，也不要将其作为执行机器人。任何未来向纸面模拟或实盘执行的演进，都需要单独进行安全审查。
