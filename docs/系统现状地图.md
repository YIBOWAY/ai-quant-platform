# 系统现状地图（2026-08-09）

面向唯一用户（一人量化研究者）的中文速查：现在系统里**什么是真的、什么是模拟的、什么被锁死**，以及每个页面/服务是干什么的。英文权威文档见 `docs/README.md` 与 `docs/OVERVIEW.md`；本文只做现状快照，不替代它们。

## 一、安全姿态（红线，勿改）

| 项 | 当前值 | 含义 |
| --- | --- | --- |
| `live_trading_enabled` | **false（唯一不可动红线）** | 任何路径都不能触发实盘下单 |
| `kill_switch` | **true（本平台的安全姿态）** | 全局熔断常开；关掉才是异常 |
| `dry_run` / `paper_trading` | true / true | 全部执行都是模拟盘 |
| `QS_LOCAL_TRUST_MODE` | true | 本机免仪式聊天（owner 会话自动签发），但不放宽任何交易红线 |
| `public_chat_write_ready` / `release_authorized` | false | 永远不会被本地开关抬升 |

前端顶栏的安全徽章（SafetyBadge）**fail-closed**：只有「仅模拟 + 实盘禁用 + 熔断开 + 论文权威就绪 + API 可达」全满足才显示绿色「仅模拟」，否则显示「安全待查」。E2E 红线断言（审批表单数为 0、无 Gate-2 控件、fail-closed 徽章）不得放宽。

## 三、页面清单（前端 3001，均带 /en /zh 双语）

### Hermes 工作台（主入口，/hermes）
- **/hermes（今日）**：问候语 + 人话状态行（「Hermes 正在值班」）+ 待处理事项 + 运行中任务 + 最近结果。真实数据，来自只读产物源。
- **/hermes 聊天**：本地信任模式下可直接发消息给 Hermes（owner cookie + CSRF + submit-turn 受管路径）。链路真实；论文投递（paper-intake）回执仍是已知堵点。
- **/hermes/sessions（会话记录）**：只读会话回放。
- **/hermes/tasks（任务）**：自动化任务与运行状态。
- **/hermes/approvals（审批）**：单次执行授权（allow-once/deny）。fail-closed：默认无可提交表单。
- **/hermes/results（结果）**：HQA 结论产物 + 平台统一结果，只读独立源。

### 研究工具
- **/strategies（策略目录）**：4 个策略可跑（横截面 Top-N、短期反转/长期动量、均值回归 Top-N、漂移状态反转草稿）；中文显示名已接入（8615b93）。真实回测引擎，sample/futu 数据。
- **/backtest、/factor-lab、/experiments**：功能保留但已从导航隐藏（91d61b9），入口收敛到策略目录与 Hermes。
- **/data-explorer**：行情数据浏览（sample + futu provider）。
- **/paper-trading、/position-map**：模拟盘账户与持仓。真实模拟账本，无实盘。
- **/options-radar、/options-screener、/options-buyside、/options-tools**：期权研究工具，数据依赖 futu。
- **/polymarket**：预测市场只读研究页。
- **/brief**：每日晨报（含公开只读分享链接）。
- **/ai-news、/agent-studio、/settings**：资讯、agent 配置、设置。

## 四、什么是真的 / 什么是模拟的

**真的**：回测引擎与因子计算、模拟盘账本、Hermes 聊天提交链路、审批 allow-once 机制、futu 行情（需网关在线）、结果产物目录。

**模拟/受限的**：一切下单都是 paper（dry_run）；`provider=sample` 数据是内置样例；漂移状态反转策略的 default_payload 用 resident momentum 占位（真实候选因子 `drift_regime_reversal_edge_v1` 只到 Gate-2，未晋升）。

**已知堵点**：P1 = paper-intake 回执（论文投递后 Hermes 回执链路未闭环，见 2026-08-01 E2E 记忆）。

## 五、常用操作

```bash
# 日常启动/重启（终端关闭后服务仍在）
bash scripts/local_mac_stack.sh start
bash scripts/local_mac_stack.sh restart
bash scripts/local_mac_stack.sh status
bash scripts/local_mac_stack.sh logs

# 测试（repo 根目录）
.venv/bin/pytest
# 前端测试
cd src/frontend && npx vitest run
# 标准项目命令（调试时可直接运行，不作为常驻方式）
python -m quant_system.cli serve --host 127.0.0.1 --port 8765
npm --prefix src/frontend run build
npm --prefix src/frontend run start -- --hostname 127.0.0.1 --port 3001
```

本地信任只省略单用户身份仪式；信任 cookie 绑定 `local_trust` 会话类型，关闭信任模式后
立即失效。运行态以 `admission_mode=local_trust` 明示，且不伪造 candidate ID/digest。
它不改变 `live_trading_enabled=false`、`kill_switch=true`、数据库迁移授权或人工 Gate。
