# 系统现状地图（2026-08-28）

这是单人本地量化助手的当前速查地图。它说明稳定边界、服务职责和有效入口，不记录
近期提交流水账。本文按 Platform `b0615fd` 与部署镜像一致的代码基线核对，不把
commit ID 当作长期状态；进程、调度和 readiness 会变化，操作前仍应运行本文的
只读检查。

## 一、稳定边界

| 主题 | 当前合同 |
| --- | --- |
| 产品形态 | Platform 提供 FastAPI、Next.js、PostgreSQL、模拟账户和研究工具；HQA/Hermes 负责编排、聊天和已安装调度。 |
| 交易安全 | `dry_run=true`、`paper_trading=true`、`live_trading_enabled=false`、`kill_switch=true`。研究结果、候选和期权推荐都不能升级为实盘订单。 |
| 本机聊天 | 当前使用 `local_trust` + connector `supervised_dispatch`。它可以让本机聊天可用，但不会抬升 `public_write_authorized` 或 `release_authorized`。 |
| 模拟账户 | PostgreSQL `canonical` 是当前事实源；数据库不可用时不回退到文件账户。 |
| 数据库迁移 | 启动固定 `QS_DATABASE_AUTO_MIGRATE=false`；正式迁移已到 034，不能在启动或日常操作中重放。 |
| 行情 | 默认真实只读 Futu/OpenD；sample 仅供明确标注的离线测试或示例流程。 |
| 正式观察 | 只有已启用模拟运行、digest 绑定的 sleeve 进入 `com.aiquant.d34-paper-cycle`；研究候选不会自动启用。 |

以上是配置和产品合同，不是永久 health 证明。现场值以 `/api/settings`、
`/api/health`、`/api/safety/effective` 和 `/api/hermes/gateway` 为准。

## 三、主要产品流

### Hermes 助手

浏览器通过同源 BFF、owner cookie 和 CSRF 提交消息。Platform 把 command 和事件写入
durable ledger，connector 再走 Hermes Session/Run 合同。聊天栏用 workspace follow
展示命令生命周期，并通过 owner/workspace 绑定的只读活动接口在对话内
显示分析、工具和回复阶段；桌面侧栏可拖拽和键盘调整宽度，移动端仍是抽屉。
只返回通用状态与耗时，不返回工具名、参数、输出或推理正文。SSE 只有收到 `ready` 才显示
实时连接，失败后明确显示重连或定时获取进度。同源 workspace 请求固定 30 秒截止：
GET 超时可重新读取，POST 超时投影 `outcome_unknown`，只能重试同一次发送。
`chat_write_ready=true` 只
证明当前本机链路可用；不能据此推断公网写入、release 或交易权限已开启。

材料完整的聊天研究必须包含 note、formula 和 ordered universe，同一 operation 只创建
一个 research-only job；材料不完整时原会话追问且零入队。研究成功停在 verified
candidate；只有通过 DSR、相关性和成本门的候选，才在 `/library` 显示绑定 exact
digest 的“启用模拟运行”动作。动作从未被手工限价单预留的模拟资金中分配
10,000 美元策略仓，不会在研究成功时自动执行。

### 模拟交易

`/paper-trading` 读取 canonical 模拟账户、策略 sleeve、账本和官方 hung-effect。
手工 paper 操作与已启用 sleeve 是不同路径：手工买卖只使用未预留手工现金和手工 lot，
策略卖出只消耗自己的 sleeve lot。正式自然观察只由 D34 paper-cycle 触发；
generic `paper strategies` 命令和旧 LaunchAgent 模板是显式的一次性/兼容入口。

### 期权推荐

`/options-radar` 显示最多 20 条真实 Futu 推荐。周一至周六 22:00 自动更新，页面的
“立即更新今日推荐”启动相同后台任务。IVR 少于 30 个正式 session 时显示“积累中”但
不阻断推荐；零条可能是所有合约都未通过硬条件，不等于数据源故障。该页面只做研究，
没有支持的 paper-options 执行路由。

## 四、有效前端入口

所有页面支持 `/zh`、`/en` locale 前缀。`/` 只在 Hermes shell feature 开启时转到
Hermes 主入口；关闭时渲染 legacy dashboard。

| --- | --- |
| Hermes | `/hermes`、`/hermes/sessions/{sessionId}`、`/hermes/results`、`/hermes/results/{kind}/{resourceId}` |
| 今日与资料 | `/watch`、`/collection`、`/library`、`/brief`、`/brief/{publicId}`、`/brief/rollup/{publicId}` |
| 策略研究 | `/strategies`、`/strategies/{runId}`、`/backtest`、`/backtest/{runId}`、`/factor-lab`、`/factor-lab/{runId}`、`/experiments`、`/docs/reversal-momentum` |

| 期权 | `/options-radar`、`/options-radar/{symbol}`、`/options-screener`、`/options-buyside`、`/options-tools` |
| 其他研究 | `/ai-news`、`/polymarket`、`/agent-studio`、`/settings` |
